## For NEW Users

- Download flutter extension from VS Code

- Download android studio

### To download Dependencies
```bash
flutter pub get
```

### To Run 
```bash
flutter run
```
Connect Mobile (Wifi Debug, Developers Option) using wifi in android studio

### To Generate App Release
```bash
flutter build apk --release
```
> App will be in "build/app/outputs/flutter-apk/app-release.apk"
